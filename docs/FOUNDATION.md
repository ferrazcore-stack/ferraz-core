# FERRAZ — Foundation

## Purpose

FERRAZ is a multi-tenant operational platform for custom-production businesses, beginning with marmorarias.

## Core principles

1. Uma informação → uma fonte oficial → muitos usos.
2. Empresa e plataforma are separate responsibilities.
3. Company data is isolated by tenant.
4. Closed orders are protected; changes use revision/addendum mechanisms.
5. Fê is a transversal intelligence layer, not the source of truth.
6. Commercial and technical responsibilities remain distinct.
7. Integrations use adapters to preserve portability.
8. Accessibility, clarity and low visual clutter are first-class requirements.
9. Critical actions require explicit authorization and auditability.
10. The platform must evolve without vendor lock-in.

## Initial operational flow

Cliente → Obra → Orçamento/Proposta → Aprovação → Pedido → Medição → Liberação Técnica → Desenho 2D → Paginação → Corte → Acabamento → Produção → Conferência → Carregamento → Romaneio → Entrega/Instalação → Termo/Recibo → Conclusão → Histórico.
